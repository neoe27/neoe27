I build multi-agent systems, and building them led me straight into the oversight problem: **when can you trust what an AI agent reports?** So I started measuring it.

- **[research-harness](https://github.com/Stonewave-Tech-LLC/research-harness)** — tooling that enforces research discipline on myself and my agents: preregistration, blinding, independent recomputation

### Open source
